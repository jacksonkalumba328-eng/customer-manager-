HOW TO RUN IN INTELLIJ
1. Unzip this folder.
2. IntelliJ: File > Open > select the CustomerManager folder (the one with pom.xml).
   Choose "Open as Project" / "Trust Project". Wait for Maven to download JavaFX.
3. Set Project SDK to JDK 17 or newer (File > Project Structure > Project).
4. Open src/main/java/app/Launcher.java and click the green Run arrow next to main.
   (Run Launcher, not Main.)
Alternative: Maven panel > Plugins > javafx > javafx:run
